# 트랙 내부 코드 매핑

시뮬레이터의 `T` 목록과 원작 카트라이더 트랙 이름을 연결하는 기준표다.
난이도는 트랙 이름 옆에 표시되는 1–5 단계 값을 뜻한다.

## 코드 규칙

- `I`: 원래 아이템전(Item)용으로 분류된 트랙
- `R`: 원래 스피드전(Racing)용으로 분류된 트랙

이 문자는 트랙이 처음 분류되던 당시의 내부 코드 성격을 나타낸다. 이후 모드
지원이 확장되었으므로 현재 플레이 가능한 모드를 완전히 제한하지는 않는다.
예를 들어 `ice_I01` 아이스 갈라진 빙산과 `village_I02` 빌리지 손가락은
`I` 코드지만 현재 스피드전에서도 사용된다.

## 출발 방향 확인 상태

13개 트랙 모두 원본 `track.1s` 메쉬를 실행 파일에 포함하고 출발선 사각형에서
스폰 위치를 얻는다. 다만 주행 방향의 부호는 메쉬에 없어 대부분 가정값이다.

| 상태 | 트랙 |
|---|---|
| 원작 대조 완료 | `forest_I01`, `village_R01` |
| 축 확실·부호 가정 | `desert_I01`, `desert_I02`, `desert_R01`, `forest_I02`, `forest_R02`, `village_I01`, `village_I02`, `village_R03` |
| 축도 추정 | `ice_I01`, `ice_I02`, `ice_R01` |

자세한 근거는 [원본 트랙 에셋 복구 파이프라인](TRACK_ASSET_PIPELINE.md)을 참고한다.

## 합성 기준 트랙

| 내부 코드 | 표시명 | 성격 |
|---|---|---|
| `flat_test` | 테스트 평지 | 메쉬 없음. 평면 지면 + AABB 벽만 |

원작 트랙이 아니라 복구한 물리를 장면 지오메트리와 분리해서 보기 위한 합성
트랙이다. 두 시뮬레이터가 이 트랙으로 시작한다. 크기는 포레스트 통나무와 같은
`896.391 x 807.183`이고 월드 원점이 중심이다.

## 수록 범위

시뮬레이터의 `T` 목록은 위 13개 트랙만 포함한다. 복구 과정에서 한때 목록에
있던 `village_C101`, `village_C102`는 현재 설치본에 동일한 `.rho`가 없어
AABB 출처를 재검증할 수 없었으므로 제거했다. 배경은
[원본 트랙 에셋 복구 파이프라인](TRACK_ASSET_PIPELINE.md)을 참고한다.
